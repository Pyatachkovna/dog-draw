# Жеребьёвка (Dog Draw) — логика и история решений

Проект: `~/dog-draw`  
Назначение: случайный стартовый порядок участников собачьих соревнований с «живой» жеребьёвкой и протоколом.

См. также: [README.md](./README.md) · [docs/РАЗРАБОТКА.md](./docs/РАЗРАБОТКА.md) · [docs/ЧЕКЛИСТ.md](./docs/ЧЕКЛИСТ.md)

---

## Как пользоваться

1. Открывать лучше через сервер, не двойным кликом по файлу:
   - ярлык `открыть.command`, или
   - `cd ~/dog-draw && python3 serve.py 8780` → http://127.0.0.1:8780/index.html
2. Вставить ссылку на Google Таблицу (доступ «все, у кого есть ссылка»).
3. Нажать «Загрузить по ссылке».
4. Выбрать, как жеребьёвать: **одним списком** или **по классам**.
5. «Провести жеребьёвку» → на экране объявляются номера по одному → протокол.

Файлы кода: `index.html`, `styles.css`, `app.js`.

## Кто попадает в список

Источник — Google Таблица (форма записи на соревнование).

### Колонки (имена могут чуть отличаться, порядок не важен)

| Смысл | Примеры заголовков |
|---|---|
| ФИО | ФИО проводника |
| Кличка | Кличка собаки |
| Порода | Порода собаки |
| Класс | Класс выступления (если колонки нет — общий список) |
| Сообщение отправлено | отправлено сообщение |
| Статус | подтверждение |
| Сумма | сумма оплаты |

### Фильтры при загрузке

1. **«отправлено сообщение»** — только значения «да» (также «да, почта», «да …»).
2. **«резерв»** — строки с «резерв» в «подтверждение» или «сумма оплаты» **исключаются**.
3. **«отказ»** — строки с «отказ» в этих же колонках **исключаются**.
4. Пустые строки и служебный мусор пропускаются.

### Фактические цифры на таблице «Запись соревнования РО» (проверка в процессе разработки)

При фильтрах выше получалось **42** участника:

| Класс | Кол-во |
|---|---:|
| РО-1 | 13 |
| РО-1 Дебют | 17 |
| РО-1 Щенки | 4 |
| РО-2 | 8 |

Пропущено типично: резерв ≈ 5, отказ ≈ 3.  
Всего в сырой таблице с «да» в сообщении было 50; без фильтра по сообщению — тоже около 50 непустых строк.

## Алгоритм жеребьёвки

Два режима в поле «Как жеребьёвать»:

1. **Одним списком, без классов** — все участники в одном перемешанном списке, нумерация с 1. Класс в протоколе не показывается.
2. **По классам отдельно** — участники делятся по классам выступления; в каждом классе свой список и нумерация с 1.

Дальше в обоих режимах:

3. Порядок перемешивается **Фишера–Йетса** (`shuffle` в `app.js`).
4. На экране номера объявляются по одному (в режиме по классам — класс за классом).
5. Протокол: один список или несколько блоков. Копирование / печать.

Если колонки класса нет, режим «по классам» ведёт себя как один список.

Выбор режима хранится в `localStorage` (`dog-draw-mode`).
Список участников после загрузки — `dog-draw-roster-v2`.
Последняя ссылка на таблицу — `dog-draw-sheet-url`.

## Загрузка Google Таблицы

1. Из ссылки извлекается id (в т.ч. из `copySourceId=` у ссылок «создать копию») и при наличии `gid`.
2. Сначала скачивается полный CSV:  
   `https://docs.google.com/spreadsheets/d/{id}/export?format=csv`  
   (все строки, в том числе скрытые фильтром листа — нужны для отсечения резерва/отказа).
3. Если `fetch` недоступен (например, открыли как `file://`) — запасной путь через gviz + JSONP.  
   Важно: в URL колбэка двоеточие в `responseHandler:имя` **нельзя** кодировать в `%3A`.

## История решений (кратко)

| Когда | Решение |
|---|---|
| Старт | Веб-страница для жеребьёвки, визуально «честная» (номера по одному), протокол. |
| Список | Колонки ФИО / порода / кличка / класс; удобная загрузка таблицы. |
| Google Forms | Реальные заголовки: ФИО проводника, Кличка, Порода, Класс (+ служебные поля). |
| Фильтр 1 | Только «отправлено сообщение» = да; «да, почта» тоже считать да. |
| Фильтр 2 | Убрать резерв и отказ. |
| Загрузка | Не CSV руками, а ссылка на Google Таблицу. |
| Баг «не грузится» | `URLSearchParams` ломал JSONP (`:` → `%3A`); плюс нужен полный export CSV. |
| Баг «список пуст» | `type="module"` не работал при открытии файла напрямую → убран; лучше открывать через http-сервер / `открыть.command`. |
| По классам | Жеребьёвка и протокол — отдельно на каждый класс выступления, своя нумерация с 1. |
| Без классов | Если колонки класса нет, не подставлять чужую колонку (дата рождения и т.п.): один общий список. Даты в «классе» игнорируются, иначе кнопка жеребьёвки блокируется. |
| Режим «одним списком» | Явный выбор в интерфейсе: жеребьёвать всех вместе, даже если в таблице есть классы. |
| Доступ к таблице | Для загрузки по ссылке таблица должна быть «Все, у кого есть ссылка» → Читатель. Иначе Google отвечает 401. |

## Где править логику в коде

| Что | Где в `app.js` |
|---|---|
| «да» в сообщении | `isYesValue` |
| резерв / отказ | `isReserveValue`, `isRejectValue` |
| разбор таблицы и фильтры | `parseTableText`, `mapColumns` |
| перемешивание | `shuffle` |
| группы по классам | `groupByClass`, `buildShuffledClassGroups`, `buildDrawGroups` |
| режим одним списком | `isFlatDraw`, поле `#draw-mode` |
| живой экран жеребьёвки | `runLiveDraw` |
| ссылка Google | `parseGoogleSheetRef`, `loadFromGoogleSheetUrl`, `fetchSheetCsvExport` |
| протокол | `renderProtocol`, копирование/печать |
