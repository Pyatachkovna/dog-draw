# Разработка Dog Draw

## Структура репозитория

```
dog-draw/
├── README.md           ← входная точка
├── ЛОГИКА.md           ← бизнес-правила и история
├── docs/
│   ├── РАЗРАБОТКА.md   ← этот файл
│   └── ЧЕКЛИСТ.md
├── index.html          ← разметка
├── styles.css          ← стили, печать
├── app.js              ← вся логика
├── serve.py            ← локальный http-сервер без кэша
└── открыть.command     ← запуск сервера + открытие в браузере
```

Зависимостей и сборки нет: правки → обновить страницу.

## Запуск

```bash
cd ~/dog-draw
python3 serve.py 8780
# http://127.0.0.1:8780/index.html
```

Скрипт `открыть.command` поднимает тот же порт (без кэша файлов) и открывает браузер. Если порт занят зависшим процессом — перезапускает его.

## Где что лежит в коде (`app.js`)

| Задача | Функции / зона |
|---|---|
| Разбор ссылки Google | `parseGoogleSheetRef` |
| Скачать таблицу | `fetchSheetCsvExport`, `fetchSheetTableJsonp`, `loadFromGoogleSheetUrl` |
| CSV → участники + фильтры | `parseTableText`, `mapColumns`, `isYesValue`, `isReserveValue`, `isRejectValue` |
| Группы по классам | `groupByClass`, `buildShuffledClassGroups`, `buildDrawGroups`, `isFlatDraw` |
| Перемешивание | `shuffle` (Фишер–Йетс) |
| Живой экран | `runLiveDraw`, `openStage`, `closeStage` |
| Протокол | `renderProtocol`, обработчики копирования / печати |
| Хранение в браузере | `localStorage`: `dog-draw-roster-v2`, `dog-draw-sheet-url` |

Разметка протокола и сцены жеребьёвки — `index.html`.  
Стили протокола по классам — `.protocol-groups`, `.protocol-class*` в `styles.css`.

## Типичные изменения

### Изменить правила отбора участников

Смотреть фильтры в `parseTableText` и хелперы `isYesValue` / `isReserveValue` / `isRejectValue`.  
После смены правил обновить раздел «Кто попадает в список» в `ЛОГИКА.md`.

### Другая колонка / заголовок таблицы

`mapColumns` — алиасы заголовков после `normalizeHeader`.

### Поведение жеребьёвки по классам

`buildDrawGroups` + `runLiveDraw` + `renderProtocol`.  
Режим «одним списком» (`#draw-mode=flat`) игнорирует классы.  
Режим «по классам» — как раньше; фильтр классов виден только в нём.

### Внешний вид

`styles.css`. Печать — блок `@media print`.

## Проверка после правок

1. Сервер запущен, страница обновлена без кэша.  
2. Загрузка по ссылке → статус с числом участников и разбивкой по классам.  
3. Жеребьёвка «одним списком» → один блок в протоколе, номера с 1.  
4. Жеребьёвка «по классам» → на экране классы по очереди, в протоколе отдельный блок на класс.  
5. Копирование / печать отдают весь протокол.  

Подробнее: [ЧЕКЛИСТ.md](./ЧЕКЛИСТ.md).

## Ограничения

- Таблица Google должна быть доступна по ссылке.  
- `export?format=csv` предпочтительнее gviz: видит строки, скрытые фильтром листа.  
- При JSONP нельзя кодировать `:` в `responseHandler:имя` как `%3A`.  
- Открытие через `file://` ненадёжно для загрузки таблицы.
