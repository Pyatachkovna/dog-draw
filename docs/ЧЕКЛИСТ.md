# Чеклист Dog Draw

## Перед соревнованием

- [ ] Страница открыта через http (`открыть.command` или `python3 serve.py 8780`)
- [ ] В Google Таблице доступ «все, у кого есть ссылка»
- [ ] Загрузка по ссылке прошла, в статусе есть разбивка по классам
- [ ] Резерв и отказ не попали в список
- [ ] Название соревнования заполнено (для протокола)
- [ ] Выбрано «Одним списком, без классов» или «По классам отдельно»
- [ ] Жеребьёвка проведена на виду у участников
- [ ] Протокол проверен: один список или по блоку на класс, номера с 1
- [ ] Протокол скопирован / распечатан

## После правок в коде

- [ ] `node --check app.js` без ошибок
- [ ] Жёсткое обновление страницы (Cmd+Shift+R)
- [ ] Загрузка тестовой таблицы работает
- [ ] Жеребьёвка одним списком даёт один блок в протоколе
- [ ] Жеребьёвка по всем классам даёт несколько блоков в протоколе
- [ ] Жеребьёвка одного класса даёт один блок
- [ ] Копирование содержит заголовки `Класс: …`
- [ ] Обновлены `ЛОГИКА.md` / README, если менялись правила
