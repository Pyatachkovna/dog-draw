# Dog Draw — жеребьёвка участников

Веб-приложение для жеребьёвки стартовых номеров на собачьих соревнованиях.

Жеребьёвка может идти **одним общим списком** или **отдельно по каждому классу** (нумерация с 1).

Открыть: https://pyatachkovna.github.io/dog-draw/

## Запуск на этом компьютере

Нужен, только если правите файлы и хотите увидеть правку сразу. Готовой ссылкой выше можно пользоваться без этого.

```bash
cd ~/dog-draw
python3 serve.py 8780
```

Открыть: http://127.0.0.1:8780/index.html  

Или дважды нажать `открыть.command` — он сам поднимет сервер, если тот не отвечает.

> Не открывайте `index.html` просто двойным кликом (`file://`) — загрузка Google Таблицы может не сработать.

## Что умеет

1. Загрузка участников по ссылке на Google Таблицу  
2. Фильтры: «отправлено сообщение» = да; без «резерв» и «отказ»  
3. Живая жеребьёвка одним списком или по классам (видно на экране)  
4. Протокол: один список или по блоку на класс → копирование / печать  

## Стек

Чистый HTML / CSS / JS, без сборки и зависимостей. Основная логика — `app.js`.
